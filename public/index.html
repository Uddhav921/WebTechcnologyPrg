    Connect your Google Sheet

    FinTrack saves every record only in your Google Sheet. One-time setup, about 3 minutes:

    1. Open your sheet → Extensions → Apps Script.
    2. Paste the code from apps-script/Code.gs and set your own SECRET.
    3. Deploy → New deployment → Web app (Execute as Me, access Anyone).
    4. Put the Web app URL and the secret in .env, then restart the app.

    Full instructions are in README.md
